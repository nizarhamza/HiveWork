# Phase 7 — Cross-Platform Polish

> Goal: each target feels native, in priority order (web → Windows → mobile).

## Web (primary)
- [ ] Deep links + route restoration
- [ ] Per-page titles
- [ ] Bundle-size pass
- [ ] Optional: PWA manifest + service worker

## Windows
- [ ] MSIX packaging
- [ ] Window sizing / state persistence
- [ ] Native menus + keyboard shortcuts
- [ ] File dialogs for attachments / exports

## Mobile (iOS + Android)
- [ ] Adaptive navigation (bottom nav / drawer)
- [ ] Gestures
- [ ] Push notifications
- [ ] Permissions handling
- [ ] Store builds (signing, icons, splash)
- [ ] Optimize for read / approve flows

**Definition of done:** each platform feels native with no layout breakage.
