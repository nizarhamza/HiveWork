# Phase 3 — Record-Detail Pattern & CRM Build-Out

> Goal: the reusable detail experience plus the first fully real module.

## Three-pane record detail (reusable template)
- [ ] Layout: list | record | properties panel
- [ ] Properties panel (status, owner, dates, tags)
- [ ] Inline editing of fields
- [ ] Activity feed / comments
- [ ] Attachments (upload / view)
- [ ] Package as a reusable scaffold modules pass content into

## Reusable data table
- [ ] Sorting
- [ ] Filtering
- [ ] Grouping
- [ ] Saved views
- [ ] Column / display options
- [ ] Row selection + bulk actions

## CRM (full CRUD)
- [ ] Contacts: create / edit / delete + detail
- [ ] Companies: create / edit / delete + detail
- [ ] Contact ↔ Company relationships
- [ ] Search, filters, saved views
- [ ] CRM actions registered in the command palette

**Definition of done:** open a contact, inline-edit it, view its history, and switch saved views — all reusable elsewhere.
